# TouchGFX设备状态页实机验证记录

> 日期：2026-08-27（Asia/Shanghai）
> 工程：BSMU_H750IB / STM32H750
> TouchGFX：4.21.4
> 当前结论：仅完成未连接ACDC/DCDC设备条件下的LCD与触摸基础验证。

## 1. 本次版本功能

- MainScreen顶部导航为：首页、设备状态、电池状态、设置。
- 设备状态页采用左右结构：左侧ACDC只读监听，右侧DCDC状态与控制。
- ACDC只使用功能码`0x03`读取，不提供控制按钮或写接口。
- DCDC启动按钮显示但禁用。
- DCDC安全停机需要5秒内二次点击，并通过现有异步Modbus写队列执行写后读回。
- `DCDC_MODBUS_PC_TEST_ENABLE=0`，Keil Watch写触发器不参与当前构建。

## 2. 已执行验证

### 2.1 构建

- TouchGFX文本、字体及图片资源生成成功。
- TouchGFX Simulator编译和链接成功。
- Keil ARM Compiler V5.06 update 7构建成功：0 errors、3个既有scatter warning。
- 已生成`BSMU_H750IB.axf`和`BSMU_H750IB.hex`。

- 主板未连接ACDC和DCDC。
- LCD正常点亮，无黑屏、花屏或明显残影。
- 首页、设备状态、电池状态和设置导航显示正常。
- 设备状态导航已改成与既有导航相同的双态PNG图片按钮。
- 页面切换和触摸响应正常。
- ACDC/DCDC未收到有效数据时，电压、电流、功率、频率、温度、模块数量、数据年龄、命令序号和错误码初始显示为0。
- 未连接设备时通信状态显示离线，DCDC工作状态不宣称为运行。

## 4. 下一阶段安全步骤

1. 保持DCDC停机，禁止发送`0x0403=4`。
2. 断电后连接RS485 A-A、B-B并建议共地。
3. EMS必须是总线唯一主站；关闭Modbus Poll/Slave并移除并联USB-RS485。
4. 先验证ACDC地址33和DCDC地址`0xFF`的只读数据显示。
5. 连续观察不少于10分钟，记录在线状态、数据年龄、错误计数、页面刷新和电池页面数据。
6. 只有现场确认允许时，才测试DCDC二次确认的安全停机；不得测试启动。
